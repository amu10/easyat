# 2026-09-23 easyAt 收尾

## 完成内容（补齐 PRODUCTION_GAPS.md 剩余 ⚠️ 项）

- **WebClient 传播（3.4）**：新增 `easy-at-spring/.../WebClientPropagator.java`，纯反射实现
  `ExchangeFilterFunction`（`ClientRequest.mutate().header().build()` + `next.exchange()`）+ `WebClientCustomizer`，
  仅当 `spring-webflux` 在 runtime classpath 时激活。原因：本地 m2 无 spring-webflux，离线 `-o` 模式加依赖会直接编译失败，
  故不能用编译期依赖，必须反射。boot2/boot3 autoconfig 各加 `@ConditionalOnClass(name="org.springframework.web.reactive.function.client.WebClient")` 的 `Object` bean。
- **加解密/脱敏 SPI 自动装配（P3）**：
  - `JacksonUndoDataCodec` 加 `UndoDataMasker masker` 字段、三参构造 `(encryptor, masker)`、`toDiagnosticString(RowImage, UndoContext)`（敏感列经 masker 脱敏）；`decodeRowImage` 补 null 守卫。
  - `UndoDataCodec` 接口加默认方法 `default String toDiagnosticString(...)`（返回 null）。
  - autoconfig 新增 `UndoDataCodec easyAtUndoDataCodec(ObjectProvider<UndoDataEncryptor>, ObjectProvider<UndoDataMasker>)`，注入到 `JdbcAtRepository(DataSource, codec)`、`RedisAtRepository(pool, codec, "easy-at")`、`ManagementService(..., codec)`。
  - `ManagementService.toMap` 追加 `undo` 列表（before/after image 经 codec.toDiagnosticString 脱敏）。
- **管理 UI（P3.4）**：新增 `easy-at-spring/.../ManagementUi.java`（从 `/management-ui.html` classpath 资源读 HTML）+ `easy-at-spring/src/main/resources/management-ui.html`（原生 JS，按状态/XID 查询、重试/回滚、token 走 `X-EasyAt-Token` header）。boot2/boot3 `EasyAtManagementController` 各加 `@GetMapping("/ui", produces="text/html")`。
- **单测**：新增 `easy-at-jdbc/src/test/.../JacksonUndoDataCodecTest.java`（3 用例：masker 脱敏、encryptor 往返、null 安全）。
