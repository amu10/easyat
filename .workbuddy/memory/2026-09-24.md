## GnuPG 安装（choco 锁失败后改用 winget）
- `choco install gnupg` 失败：`C:\ProgramData\chocolatey\lib\effcb...` 锁文件被占（NuGet 崩溃遗留）。诊断确认无残留进程/`.lock`/`effcb` 目录后放弃 choco。
- 改用 `winget install --id GnuPG.GnuPG -e --source winget --accept-package-agreements --accept-source-agreements --silent`，退出码 0，装到 `C:\Program Files\GnuPG\bin\gpg.exe`（v2.5.24），已写入**系统 PATH**。
- 注意：agent 沙箱子进程不重新加载注册表 PATH，故本会话内 `Get-Command gpg` 仍为空；用户**新开终端**即可直接用 `gpg`。
- 下一步（用户本人执行）：`gpg --full-generate-key`（姓名 amu10、GitHub 关联邮箱、设 passphrase）→ `gpg --list-secret-keys --keyid-format LONG` 取 KEY_ID → `gpg --keyserver keyserver.ubuntu.com --send-keys <KEY_ID>`，详见 `RELEASING.md` 第 2 节。
